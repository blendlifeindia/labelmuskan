Build a simple, clean and easy-to-use backend operational dashboard for Label Muskan, a designer clothing label/boutique.

The main goal is to make the dashboard extremely simple for the studio team to update every day, while giving the owner a clear picture of orders, production, expenses, purchases, salaries and monthly profit/loss.

The dashboard should NOT feel like complicated accounting software. Staff should be able to update information quickly, ideally entering each piece of information only once, with the rest of the dashboard updating automatically.

1. ORDERS — Main Dashboard
This should be the most important section.

Every order should have:

Order number
Client name
Order date
Delivery date
Outfit/product
Selling price
Advance received
Balance payment
Payment status
Production status
Assigned staff
Notes
Most important: Orders should automatically be sorted by earliest delivery date first, so the most urgent/closest deliveries always appear at the top.

Production status options:

New Order
Measurement Pending
Fabric Pending
Cutting
Stitching
Embroidery/Handwork
Trial Pending
Alteration
Ready
Delivered
Cancelled
The home page should clearly show:

Deliveries due today
Deliveries due in the next 3 days
Pending orders
Overdue orders

Outstanding: ₹3,60,000
EXPENSES

Salaries: ₹3,40,000
Rent: ₹1,20,000

Other Expenses: ₹65,000
Total Expenses: ₹12,80,000

Estimated Profit: ₹8,60,000

Profit Margin: 40.2%

This should be generated automatically from the data entered throughout the month.

MOST IMPORTANT DESIGN PRINCIPLE
The dashboard should be simple enough that staff actually update it every day.

Do not make staff enter the same information multiple times.

For example:

If staff enters:

Order #124 — ₹48,000 — Delivery 15 Oct

that information should automatically flow into:

Orders
Sales
Payments
Monthly summary
Profit calculation
Similarly, when a ₹12,000 fabric purchase is entered, it should automatically contribute to the monthly expense/profit calculation.

HOME PAGE SHOULD ANSWER ONLY THESE QUESTIONS:
What orders are coming up?
What needs attention today?
How much have we sold this month?
How much have we collected?
How much is pending?
How much have we spent?
How much profit/loss have we made?
Keep the interface minimal, clean and visually easy to understand, with as little manual calculation as possible.

The priority is operational clarity, not complicated analytics.
